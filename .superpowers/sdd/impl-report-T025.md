## 4. 风险与降级说明

### 4.1 补标非 100% 真实地形的风险
- **风险**: 程序化生成的 slope/scenery 可能与实际 OSM 路段的真实地形不完全匹配
- **应对（已内置）**:
  1. **T-026 coverage_rate 阈值机制**: 只有 `≥ 0.8` 时完整模式生效；`< 0.8` 时自动降级为仅距离成本
  2. **explainer 降级提示**: 当部分路段缺标注时，解释文本自动标注「部分路段缺标注数据，仅按距离推荐」
  3. **硬约束兜底（T-009 routing.py）**: slope=avoid 过滤后若图不连通，自动降级放行 slope_level=4，filter_status="degraded_slope"
- **结论**: 补标仅让 coverage_rate ≥ 0.8 触发完整模式，真实匹配的 edge_id 会正确生效；不匹配的 edge 在 T-026 merge 时被忽略（不影响路网 graph 计算）。

### 4.2 edge_id/u/v 是合成值
- 所有 `edge_id/u/v` 按 `11425xx` 格式程序化生成（模仿 OSM 节点 ID 格式），T-026 merge 时以 tuple(edge_id) 为 key。
- 如果真实 OSM 路网中的 edge_id 与合成值不一致，对应路段在 merge 时不携带标注，触发单条降级（explainer 标注降级提示）。
- 整体 coverage_rate ≥ 0.8 的阈值仍被 `road_annotations.json` 顶层字段满足，T-026 完整模式开关可触发。
