# 07 · 前端指南

## 单页应用结构

`static/index.html` 是单页应用入口，主要区域：
- 顶部固定栏：标题 + 出行方式切换 + 天气徽章
- 欢迎卡片：冷启动引导（珞珈门→樱顶、赏樱路线等快捷入口）
- 对话区：用户气泡 + 机器人气泡
- 输入框 + 快捷 Chip（最短/风景/平坦）
- 地图区：高德底图 + 路径绘制
- 结果区：默认 hidden，规划后才显示

## 出行方式切换

顶部固定栏按钮：
- 🚶 步行（粉色路线）
- 🚴 骑行（绿色路线）
- 🚗 驾车（蓝色路线）

切换时自动重算当前请求的路线。前端实现 sequence tracking 保护，防止旧响应覆盖新状态。

驾车模式自动隐藏"平坦优先"选项（无意义）。

## PWA

- `manifest.json` — 应用名"珞珈智行"、图标、主题色
- `sw.js` — Service Worker v3，网络优先策略
  - 页面导航：network-first，失败回退缓存
  - 静态资源（CSS/JS/JSON）：版本化缓存，max-age=3600
- CSS/JS 引用带版本号，强制浏览器更新

## 天气徽章

顶部徽章显示天气 + 气温（如"晴 23°"）。hover 显示出行建议。

## 冷启动引导

首次进入显示欢迎卡片，含 2 个快捷入口：
- 经典路线 珞珈门→樱顶
- 赏樱路线 珞珈门→樱花大道

点击直接发起规划请求。

## 快捷 Chip

输入框下方 3 个快捷模式：
- 最短路径（distance_first）
- 风景优先（scenery_first）
- 平坦优先（slope_avoid，驾车模式隐藏）

点击 Chip 生成用户气泡（如"帮我规划最短路径"）并触发规划。

## 对话气泡

所有用户输入和系统响应都通过对话气泡反馈：
- 成功规划：显示后端 `explanation` 字段
- 业务错误（如校外地点）：气泡提示，不弹窗
- 网络错误：弹窗提示
- 思考中：临时"正在思考…"气泡，响应后更新

## 路况上报

需要管理员登录：
1. POST /api/admin/login（密码校验）
2. 登录态写入 session
3. 显示上报表单
4. 非 admin 用户无法上报或删除路况

## 地图可视化

- 路线按出行方式分色
- 途经 POI 标记：路线 100m 内、高德评分 ≥4.3、按评分排序、最多 8 个
- 非路径规划响应时自动清理路线和结果区

## 快捷键

`?` 打开快捷键帮助弹窗。详见 [static/index.html](../static/index.html) 快捷键部分。
