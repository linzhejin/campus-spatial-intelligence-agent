# 05 · 架构设计

## 三层架构

```
用户输入
   ↓
┌─────────────────────────────────┐
│ 1. 解析层 agents/parser.py       │  NL → TaskIntent (Pydantic)
│   LLM 两阶段：原文名提取 → POI 归一化 │
└─────────────────────────────────┘
   ↓
┌─────────────────────────────────┐
│ 2. 规划层 spatial/routing.py     │  TaskIntent → 路径
│   多因素加权 Dijkstra + 出行方式过滤 │
└─────────────────────────────────┘
   ↓
┌─────────────────────────────────┐
│ 3. 解释层 agents/explainer.py    │  路径 + 数据 → 自然语言
│   结构化数据驱动，LLM 仅润色       │
└─────────────────────────────────┘
   ↓
返回前端
```

## 核心模块

### agents/ — LLM 智能体
- `parser.py` — 自然语言解析（temperature=0.0 确定性输出）
- `explainer.py` — 路线解释生成（temperature=0.2 减少虚构）
- `prompts/` — 5 个系统 prompt 模板（parse/explain/chat/poi_guide/suggest）

### api/ — REST 接口
- `routes.py` — 15 个端点，含管理员鉴权装饰器

### spatial/ — 空间计算
- `network.py` — OSMnx 路网下载与缓存
- `routing.py` — 多因素加权路径规划、出行方式过滤
- `poi.py` — POI 查询、别名归一化、模糊匹配
- `road_conditions.py` — 路况事件管理
- `coord_transform.py` — GCJ-02 ↔ WGS-84 转换
- `weather.py` — 高德天气接口

### static/ — 前端
- `index.html` — 单页应用
- `js/app.js` — 交互逻辑
- `css/style.css` — 珞珈秋色主题
- `manifest.json` / `sw.js` — PWA 配置

## LLM 两阶段解析

**阶段 1**：LLM 只做原文地名提取，不注入 POI 列表（避免 320+ POI 撑爆 token）。

**阶段 2**：后端 `_normalize_poi_refs` 用本地 POI 库做地名归一化：
- 数字归一（"七舍" ↔ "7舍" ↔ "十四舍" ↔ "14舍"）
- 别名匹配（"主入口" → "珞珈门"）
- 模糊候选（多候选返回 ambiguity 让用户确认）

## 坐标系统

| 数据 | 坐标系 | 说明 |
|---|---|---|
| POI / 校园多边形 | GCJ-02 | 高德地图标准，前端底图 |
| 路网 | WGS-84 | OSM 标准 |
| DEM 坡度 | WGS-84 | SRTM/ASTER |

路径绘制时 `_coords_wgs_to_gcj` 将路网坐标转换到 GCJ-02 再返回前端，避免 50-100m 偏移。

## 坡度软降级

陡坡边不硬过滤，而是施加 3x 软惩罚。原因：硬过滤可能导致起终点不可达。仅在用户显式 slope=avoid 时启用。

路况封闭边同理：硬删除后若起终点不可达，自动降级为 1000x 惩罚保路线可用。

## 出行方式过滤

`filter_graph_for_mode(G, mode)` 返回过滤后的子图 + penalty_map：

| 模式 | 过滤规则 |
|---|---|
| walk | 不过滤，全部边可用 |
| bike | 剔除台阶/电梯边；陡坡软惩罚 |
| drive | 剔除步行专用边；过滤后清理孤立节点 |

## 路径成本模型

```
cost = Σ (w_distance × length/max_len + w_slope × slope_level/5 + w_scenery × (1 - scenery_level/5))
```

权重约束：每维 [0.05, 0.8]，三者之和 = 1.0。

## 请求序列保护

前端实现 sequence tracking，每次请求带递增 seq。响应到达时比较 seq，旧请求（seq < 当前）被丢弃，防止旧响应覆盖新 UI 状态。
