## POI 字段

```json
{
  "id": "poi_140",
  "name": "珞珈门",
  "aliases": ["牌坊", "主入口", "八一路牌坊", "国立武汉大学牌坊", "校门", "正门", "武大正门", "国立武汉大学牌楼"],
  "coordinates": {"lng": 114.358238, "lat": 30.53334},
  "type": "gate",
  "campus": "文理学部",
  "category": "gate",
  "description": "武大正门八一路老牌坊，国立武汉大学题字，校园主入口",
  "scenery_score": 1,
  "rating": null
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一标识，格式 `poi_NNN` |
| `name` | string | 默认名称（已消歧，如"总馆"而非"图书馆"） |
| `aliases` | array | 别名列表（含数字归一化后的形式） |
| `coordinates` | object | `{lng, lat}`，GCJ-02 坐标系 |
| `type` | string | gate/scenery/teaching/dining/library/sport/service/dorm |
| `campus` | string | 文理学部 / 工学部 / 信息学部 |
| `category` | string | 细分类 |
| `description` | string | 描述 |
| `scenery_score` | int | 1-5 景观评分 |
| `rating` | float\|null | 高德评分（164 个 POI 有评分） |

## POI 范围约束

- 仅含文理/工学/信息三学部范围内 POI
- 包含校内中大型服务设施：校医院、自强超市、工行、邮政、活动中心
- 排除校外地点、小商铺（奶茶/餐饮/快递/KTV）、教工宿舍/家属区/私人公寓

## 校门（13 个）

完整校门列表，含坐标。近似坐标会标注（如西南门）。

## 路网边属性

边数据存储在 `road_annotations.json`，键为 `"u,v,key"` 节点对：

```json
{
  "length": 23.5,
  "slope_level": 3,
  "scenery_level": 4,
  "geometry": "LINESTRING (114.36 30.53, ...)",
  "road_name": "樱花大道"
}
```

| 字段 | 说明 |
|---|---|
| `length` | 边长度（米） |
| `slope_level` | 1-5 坡度等级（DEM 计算，1 平坦 / 5 陡峭） |
| `scenery_level` | 1-5 景观等级（樱花大道/湖滨路=5，环山道=4） |
| `geometry` | WKT LINESTRING，含弯道中间点 |
| `road_name` | OSM 道路名（2614 条边有真实名，占 20.8%） |

## 坐标系

| 数据 | 坐标系 |
|---|---|
| POI / 校园多边形 | GCJ-02 |
| 路网 | WGS-84（自动转换后画图） |
| DEM | WGS-84 |

## 数据源

- POI：高德 Web 服务 API（place/around/regeo）+ OSM + 人工校对
- 路网：OSMnx（WGS-84）
- 坡度：SRTM/ASTER DEM
- 校园多边形：人工绘制 v7 版
- 验证：shapely 几何校验 + ~65 锚点 PIP 校验

## 已知限制

- 西南门坐标为近似值
- 短边（<50m）坡度为占位符
- 校区 1-2 边界存在固有模糊性
- 246 个 POI 无高德评分
