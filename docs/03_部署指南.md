# 03 · 部署指南

## 目标环境

- 腾讯云 CVM
- 公网访问：http://152.136.102.172:5000
- systemd 服务名：`whu-walker.service`
- 服务器项目路径：`/home/ubuntu/campus-spatial-intelligence-agent`

## 服务器准备

```bash
# 安装系统依赖
sudo apt update
sudo apt install -y python3 python3-venv python3-pip git

# 拉取代码
cd /home/ubuntu
git clone <repo-url> campus-spatial-intelligence
cd campus-spatial-intelligence-agent

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt gunicorn
```

## 环境变量

创建 `.env` 或通过 systemd 注入（推荐后者）：

```env
DEEPSEEK_API_KEY=sk-xxx
AMAP_KEY=xxx
AMAP_SECURITY_CODE=xxx
FLASK_ENV=production
SECRET_KEY=随机长字符串
ROAD_CONDITION_ADMIN_PASSWORD=你的管理员密码
CORS_ORIGINS=https://your-domain.com
```

## systemd 服务

编辑 `/etc/systemd/system/whu-walker.service`：

```ini
[Unit]
Description=WHU-Walker Campus Spatial Intelligence Agent
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/campus-spatial-intelligence-agent
Environment=FLASK_ENV=production
Environment=DEEPSEEK_API_KEY=sk-xxx
Environment=AMAP_KEY=xxx
Environment=AMAP_SECURITY_CODE=xxx
Environment=SECRET_KEY=随机长字符串
Environment=ROAD_CONDITION_ADMIN_PASSWORD=你的管理员密码
ExecStart=/home/ubuntu/campus-spatial-intelligence-agent/venv/bin/gunicorn \
  --workers 2 --threads 4 --timeout 60 --max-requests 1000 \
  --bind 0.0.0.0:5000 app:app
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

### gunicorn 硬约束

- **必须** 使用 `--workers 2 --threads 4 --timeout 60 --max-requests 1000`
- **禁止** 使用 `--preload`（多 worker 共享全局对象会冲突）
- **禁止** 使用 `--keepalive` 和 `--max-requests-jitter`（本版本不识别，启动失败）

## 健康检查

`/api/health` 端点必须存在，负载均衡器通过它监控服务状态：

```bash
curl http://152.136.102.172:5000/api/health
# {"status":"ok","project":"珞珈智行","timestamp":...}
```

## 启动

```bash
sudo systemctl daemon-reload
sudo systemctl enable whu-walker
sudo systemctl start whu-walker

# 查看状态
sudo systemctl status whu-walker

# 查看日志
sudo journalctl -u whu-walker -f
```

## 更新部署

```bash
cd /home/ubuntu/campus-spatial-intelligence-agent
git fetch origin
git reset --hard origin/main
sudo systemctl restart whu-walker
```

## 路网预热

生产模式下，应用启动时后台线程自动调用 `load_or_download_network()` 预热路网，避免首次请求冷启动延迟。

## 高德 Referer 白名单

在高德控制台设置 Referer 白名单包含你的域名（如 `152.136.102.172:5000`），否则 JS API 会报 `INVALID_USER_KEY`。
