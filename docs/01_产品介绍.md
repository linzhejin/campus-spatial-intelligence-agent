# 01 · 产品介绍

## 一句话介绍

**珞珈智行（WHU-Walker）** 是武汉大学校园出行智能体：像熟悉校园的本地同学一样，用一句自然语言帮师生与访客解决"去哪儿、怎么走"，覆盖步行 / 骑行 / 驾车三种方式，提供带语音播报的实时步行导航。

- 在线访问：https://whuspati.online
- Android 安装包：https://whuspati.online/app/whu-walker.apk

## 覆盖范围

覆盖文理学部、工学部、信息学部三个校区。POI 数据（[data/pois.json](../data/pois.json)）当前收录 **420 个地点**、**12 个校门**，按类型分布：

| 类型 | 数量 | 说明 |
|---|---|---|
| dining 餐饮 | 127 | 食堂、快餐、茶饮、咖啡、餐厅 |
| study 学习 | 113 | 教学楼、教室、图书馆等 |
| dorm 宿舍 | 101 | 学生宿舍区 |
| scenery 景点 | 29 | 樱花大道、老斋舍、樱顶、珞珈山等 |
| sports 运动 | 19 | 体育场、场馆 |
| gate 校门 | 12 | 见下方名单 |
| service 服务 | 11 | 校医院、商超等公共服务 |
| area 片区 | 8 | 樱园、梅园、桂园、枫园等片区 |

按校区分布：文理学部 234 个、工学部 90 个、信息学部 88 个，另有 8 个跨校区（whu）地点。

12 个校门：凌波门、珞南门、科技门、珞珈门、茶港门、洪波门、文澜门、珞瑜二门、珞瑜门、弘毅门、北门、扬波门。其中珞珈门是文理学部正门（八一路牌坊），珞瑜门是信息学部正门，命名易混点已写入智能体的系统提示，避免把凌波门、扬波门、珞南门等讲混。

## 核心特性

### 全 Agent 自然语言交互

所有用户输入（包括明确的 A→B、闲聊、天气、路况查询）都进入同一个 Plan-Act-Observe 智能体循环（[agents/planner.py](../agents/planner.py)），由大模型自主决策调用工具或直接回答，而不是写死的意图分支。智能体可调用 9 个工具：

`resolve_poi`（地名消歧）、`search_poi_candidates`（找候选）、`plan_route`（两点规划）、`plan_via_route`（途经点规划）、`plan_tour`（游览路线）、`get_weather`（天气）、`list_road_conditions`（路况）、`ask_user`（缺信息时追问）、`suggest_followup`（跟进问题推荐）。

循环设 6 轮上限与 40 秒总预算；路线产出后立即收尾，答复直接由结构化结果拼装，距离 / 时长 / 坡度等数字只引用工具返回值。典型说法：

- "从教五去总图书馆，**顺路买咖啡**" → `plan_via_route`，找不到合适途经点时仍给出主路线并文字说明；
- "想**逛遍全校** / 带我转转" → `plan_tour` 生成游览路线；
- "从**我这**到樱顶" → 注入 GPS 坐标作为起点（`type=coord`）；
- "南门到樱花大道" → 先分辨南门指珞南门还是珞瑜门，不确定就追问；
- 多轮承接："我想从珞珈门" → "去樱顶" → "避开陡坡"。

### 多因素路径规划 × 三种出行方式

路线成本由距离、坡度、景观三维加权，权重区间 [0.05, 0.8] 且和为 1。无偏好的普通请求不额外设权重，直接用各方式的默认值（[spatial/routing.py](../spatial/routing.py) 的 `MODE_DEFAULT_WEIGHTS`）：

| 方式 | distance | slope | scenery |
|---|---|---|---|
| 🚶 步行（默认） | 0.80 | 0.05 | 0.15 |
| 🚴 骑行 | 0.60 | 0.25 | 0.15 |
| 🚗 驾车 | 0.85 | 0.05 | 0.10 |

骑行默认更在意坡度（剔除台阶 / 电梯边），驾车优先校园车行道、剔除步行专用边。"赶时间""膝盖不好别爬坡""想看风景"等说法由智能体转成对应权重与硬约束；也可以在界面上直接切换方式或用偏好快捷键。每次规划同时返回**推荐路线**与**最短路径**两条结果，地图双线对比。

### 智能避坡

校内路网每条边带由 DEM 高程数据离线计算的 `slope_level`（1–5）。选择"平坦优先"（constraints.slope=avoid）时，slope_level=5 的陡坡边直接剔除，4 级边加 2× 距离惩罚；若剔除后该起终点不可达，则不删边、改让 5 级边承担 3× 成本（4 级维持 2×）软降级重试，保证任何 OD 都有路线。雨雪天湿滑时，4/5 级边还会被额外加罚。

### 实时路况，全方式生效

施工、活动、封闭、积水、事故五类路况由管理员上报到具体路段（[data/road_conditions.json](../data/road_conditions.json)），路线计算按"方式 × 类型"分别处理（[spatial/road_conditions.py](../spatial/road_conditions.py)）：封闭对所有方式禁行；施工对骑行 / 驾车禁行、步行加 1.5× 惩罚；积水对步行 / 骑行禁行；活动 / 事故也有各自的惩罚或禁行规则。**步行同样会绕行封闭路段**，不存在"步行不受路况影响"的情况。路况到期自动失效，也可由管理员随时结束。

### 天气与季节感知

- 天气：`get_weather` 拉取高德实时天气（武汉，服务端 30 分钟缓存）。雨雪天对陡坡 / 台阶边加罚（智能避坡），35°C 以上高温倾向树荫景观路，并在回复中给出风、雾、霾等提示。
- 季节：任务卡知识（[data/task_cards.json](../data/task_cards.json)）按当前月份的季节加权召回，例如"赏樱"卡在春季加分，并提醒樱花季可能临时管制、规划前先查路况。

### 语音交互

- **语音输入**：麦克风按钮"按住说话"——按住聆听、松开发送、上滑取消，30 秒自动松手；页面上是紧凑的聆听胶囊卡片（实时转写 + 音量动效），不弹系统全屏听写面板。浏览器内走 Web Speech API（zh-CN），Android App 内走原生 SpeechRecognizer。
- **语音播报**：导航指令 TTS 语音播报，App 内优先 Android 原生 TextToSpeech，浏览器降级 speechSynthesis；新指令打断旧播报，可一键静音。

### 实时步行导航

规划后可进入"高德同款"沉浸导航态：北朝上地图跟随、顶部转向指令卡（远距预报 → 临近动作令 → 到达）、语音播报、剩余距离 / 时间、屏幕常亮。前端把 GPS 蓝点投影到路线折线上，步行偏离路线超过 20 米并连续两点确认后**静默自动重算**（骑行 30 米、驾车 35 米），重算冷却 30 秒；箭头在沿线行进时吸附所在路段方位角，消除手机罗盘磁偏干扰。

### PWA 与 Android 应用内更新

- PWA：提供 Web App Manifest（standalone 独立运行、主题色 #8B3A3A、三条快捷方式），可添加到手机主屏幕全屏使用；Service Worker 脚本（[static/sw.js](../static/sw.js)，当前 `whu-walker-v47`）定义了静态缓存 / 接口 SWR / 第三方直连三策略。
- Android APK：零第三方依赖的 WebView 壳（包名 `online.whuspati.app`，当前 v1.4.1 / versionCode 6），网页与浏览器共用同一套前端。启动时检查 [static/app/latest.json](../static/app/latest.json)，发现新版本弹窗提示、后台下载、SHA-256 校验后经系统安装器覆盖安装，无需应用商店。

## 技术栈

| 层级 | 选型 |
|---|---|
| 前端 | 原生 JavaScript（无框架）+ Leaflet 1.9.4（本地化部署）+ 高德地图瓦片（GCJ-02 矢量 / 卫星） |
| 定位 | 高德 JS SDK 2.0（仅用 Geolocation 混合定位，加载失败降级浏览器原生定位）；App 内走原生 LocationManager |
| 语音 | Web Speech API（识别 / 合成）+ Android 原生 SpeechRecognizer / TextToSpeech 桥 |
| 后端 | Flask 3 + flask-cors，gunicorn（2 workers × 4 threads，timeout 60s）+ systemd |
| 智能体 | DeepSeek（deepseek-chat，OpenAI 兼容接口），Plan-Act-Observe 工具调用循环 |
| 路网算法 | NetworkX（图加载 + Dijkstra）+ Shapely；OSMnx 仅用于离线路网构建（requirements-dev） |
| 空间数据 | 420 POI + 12 校门、路网边标注（slope_level / scenery_level）、DEM 坡度、路况事件 |
| 坐标系 | 后端路网 WGS-84；前端地图 / POI / 路线统一 GCJ-02，双向转换（spatial/coord_transform.py） |
| 部署 | 腾讯云 CVM，Caddy 反向代理提供 HTTPS（whuspati.online → gunicorn:5000） |
| Android | 原生 WebView 壳（minSdk 26 / targetSdk 34），aapt2/javac/d8/apksigner 手工构建链 |
