# 01 · 产品介绍

## 名称

**珞珈智行**（WHU-Walker）— 武汉大学校园空间智能体。

## 定位

面向武大师生与访客的校园步行/骑行/驾车导航助手。用一句自然语言描述出行需求，系统自动解析空间偏好（距离 / 坡度 / 景观），结合三校区路网与 POI 数据，规划最贴合用户意图的路线。

## 覆盖范围

文理学部、工学部、信息学部三校区，含 13 个校门、410+ POI、4571 节点 / 12550 边的校内路网。校外地点（华师、华科等）返回边界提示。

## 核心特性

### 🗺️ 多因素路径规划
距离、坡度、景观三维加权。用户可说"最短路径""避开陡坡""走风景好的路"，系统自动转换为权重组合。

### 🚶🚴🚗 三种出行方式
步行（默认）/ 骑行 / 驾车，支持自然语言识别（"骑车""开车""走路"），切换时自动重算路线。
- 步行：使用全部边
- 骑行：剔除台阶/电梯边，陡坡软惩罚
- 驾车：剔除步行专用边，过滤后清理孤立节点

### 💬 自然语言交互
- 一句话完成解析 + 路径规划 + 解释生成
- 多轮对话承接上下文（"我想从珞珈门" → "去樱顶" → "避开陡坡"）
- 模糊地名候选确认（"七舍" 可能是 7 舍或十四舍）

### 🏔️ 智能避坡
DEM 坡度数据标注每条边的 slope_level（1-5）。用户说"膝盖不好"自动 slope=avoid；陡坡边施加 3x 软惩罚而非硬过滤，保证可达性。

### 🌸 季节感知
POI 标注季节标签（春樱 / 夏荫 / 秋桂 / 冬梅），推荐路线考虑当季景观。

### 🚧 路况上报
管理员登录后可上报封闭 / 施工 / 事故路况。按类型分级处理：
- 封闭 / 施工：骑行驾车模式硬删除边（不可达时降级为 1000x 惩罚）
- 事故：骑行驾车 3x 惩罚
- 步行模式不受影响

### 📱 PWA
可添加到手机主屏幕。Service Worker v3 网络优先策略，版本化缓存避免旧 UI。

### 🎨 珞珈主题
珞珈秋色配色（樱花粉 + 翡翠绿），出行方式分色：步行粉 / 骑行绿 / 驾车蓝。

## 技术栈

| 层级 | 选型 |

| 前端 | 高德 JS API 2.0 + Vanilla JS + PWA |
