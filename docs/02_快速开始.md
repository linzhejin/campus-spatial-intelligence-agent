# 02 · 快速开始

## 环境要求

- Python 3.11+（代码使用 `str | None` 语法需 3.10+；部署镜像基准为 Python 3.11）
- Windows 推荐 PowerShell；命令均给出 PowerShell 写法

## 获取代码与安装依赖

```powershell
git clone <repo-url>
cd campus-spatial-intelligence-agent
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

仅当需要在本地重新下载 OSM 路网时，再装开发依赖（含 osmnx/geopandas）：

```powershell
pip install -r requirements-dev.txt
```

## 配置环境变量

复制 `.env.example` 为 `.env`，至少填入 LLM 与高德两组密钥：

```powershell
Copy-Item .env.example .env
```

```env
# LLM（DeepSeek，OpenAI 兼容协议）
DEEPSEEK_API_KEY=sk-your-key-here
OPENAI_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

# 高德 JS API 2.0（前端地图底图）
AMAP_KEY=your-amap-key-here
AMAP_SECURITY_CODE=your-amap-security-code-here

# 本地开发
FLASK_ENV=development
FLASK_PORT=5000
```

`.env.example` 中还可调整（均有内置默认值）：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `MAP_CENTER_LAT` / `MAP_CENTER_LNG` | 30.5365 / 114.3630 | 地图初始中心 |
| `MAP_ZOOM` | 16 | 初始缩放 |
| `WHU_BBOX_NORTH/SOUTH/EAST/WEST` | 见 `.env.example` | OSM 路网下载边界框 |
| `CORS_ORIGINS` | 空（生产才生效） | 逗号分隔的允许来源 |

以下变量由代码读取、但 `.env.example` 未列出，按需自行追加（生产部署建议配置，详见 [03_部署指南](03_部署指南.md)）：

- `SECRET_KEY`：Flask session 密钥（管理员网页登录态依赖）
- `ROAD_CONDITION_ADMIN_PASSWORD`：管理员网页登录口令；不设置则登录入口关闭
- `ROAD_CONDITION_ADMIN_TOKEN`：外部系统（如保卫部）对接 Token，请求头 `X-Admin-Token` 或 `Authorization: Bearer`

> `DEEPSEEK_API_KEY` 缺失或 LLM 服务故障时，请求会自动落回旧的 parser 规则管道，服务不中断；高德 Key 缺失会影响地图底图与天气接口。

## 初始化路网

路网缓存文件为 `data/whu_road_network.graphml`（约 4.6MB，已被 `.gitignore` 忽略，不随仓库分发）：

- 缓存已存在时，首次规划请求直接加载（< 1s）；
- 缓存不存在时自动从 OSM 下载（约 30s，**需要安装 `requirements-dev.txt` 中的 osmnx**），下载后写缓存；
- 生产模式（`FLASK_ENV=production`）启动时另有后台线程预热路网，无需手动触发。

手动操作方式（任选其一）：

```powershell
# 强制删除缓存并重新下载（覆盖三学部扩展路网）
python scripts/network/rebuild_network.py

# 或启动服务后调用初始化端点（POST /api/network/init，首次下载约 30s，之后返回 cached=true）
curl.exe -X POST http://localhost:5000/api/network/init
```

路网覆盖率/连通性校验（独立实时下载一份 OSM 步行道网络做 P0 校验，同样需要 osmnx）：

```powershell
python scripts/validate/validate_osm_network.py
```

## 启动服务

```powershell
python app.py
```

打开浏览器访问 http://localhost:5000 。端口可用 `FLASK_PORT` 环境变量修改（也兼容平台注入的 `PORT`）。

健康检查：

```powershell
curl.exe http://localhost:5000/health
# {"project":"珞珈智行","status":"ok","timestamp":...}
```

## 出行方式

页面顶部固定栏提供 🚶 步行 / 🚴 骑行 / 🚗 驾车切换按钮（`.travel-mode-btn`，默认步行），也可在自然语言中直接说「骑车」「开车」「走路」等关键词（关键词纠偏优先级最高），切换或显式提及后自动按对应方式重算路线。
