# 09 · 故障排查

## 常见问题

### 天气接口返回 INVALID_USER_KEY

**原因**：高德 Web API Key 配置错误或 Referer 白名单未设置。

**解决**：
1. 检查 `.env` 或 systemd 中 `AMAP_KEY` 是否正确
2. 高德控制台 → 应用管理 → 添加 Referer 白名单（含 `152.136.102.172:5000`）
3. 确认 `AMAP_SECURITY_CODE` 已配置（JS API 2.0 需要安全密钥）

### 路线穿越封闭区域

**原因**：路况 geometry 字符串解析失败（WKT 未转 shapely）或硬删除导致网络断开。

**解决**：已通过 `isinstance` 检查 + `wkt.loads()` 修复；封闭边改用 1000x 软惩罚降级。若仍出现，检查 `data/road_conditions.json` 中 geometry 格式。

### 驾车"假不可达"

**原因**：驾车过滤后 POI 吸附到无路节点。

**解决**：已实现过滤后清理孤立节点。若仍报"驾车无法到达"，提示用户切换骑行或步行。

### gunicorn 启动失败

**禁止参数**（本版本不识别）：
- `--preload` — 多 worker 共享全局对象冲突
- `--keepalive`
- `--max-requests-jitter`

**必须参数**：`--workers 2 --threads 4 --timeout 60 --max-requests 1000`

### LLM 解析失败降级

**现象**：DEEPSEEK_API_KEY 未配置或调用失败。

**行为**：自动降级为规则兜底解析（`_fallback_task_intent`），返回 ambiguity="解析失败，请尝试更明确的描述"。

**解决**：检查 `.env` 中 `DEEPSEEK_API_KEY`，确认 OpenAI SDK 已安装。

### 校外地点返回

**现象**：查询"华师""华科""武体"返回边界提示。

**原因**：规则层 + LLM 引导层双重拦截，POI 库不含校外地点。

### POI 名称匹配失败

**原因**：中文数字与阿拉伯数字未归一（"七舍" ≠ "7舍"）。

**解决**：已实现数字归一化。若仍失败，检查 `data/pois.json` 中 aliases 是否包含数字归一化后的形式。

## 路网不可达排查

1. 确认路网已加载：`python scripts/validate/validate_osm_network.py`
2. 检查路况事件：`GET /api/road-conditions`
3. 临时删除所有路况：清空 `data/road_conditions.json` 为 `[]`
4. 重启服务

## 硬约束清单

- POI 不含校外地点、小商铺、教工宿舍
- 路网裁剪到校园边界外扩 120m（保留校门过街）
- LLM parser temperature=0.0，explainer temperature=0.2
- 路线分色：步行粉 / 骑行绿 / 驾车蓝
- 管理员密码通过 systemd 环境变量 `ROAD_CONDITION_ADMIN_PASSWORD` 设置
- 232 测试必须全过
- 13 校门条目必须完整
