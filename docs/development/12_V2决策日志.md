## DEC-021: 全 Agent 架构 — planner 循环 + function calling，旧管道降级为兜底

- 日期: 2026-08（补录 2026-09）
- Decision: 主链路从"parser 一把出 TaskIntent"改为 `agents/planner.py` Plan-Act-Observe 循环：LLM 自主选择工具、传参、观察结果、再决策或作答
- 选择:
  - 所有输入（问路/闲聊/天气/路况/游览）统一进 Agent，最多 6 轮、总预算 40s（gunicorn 60s 内留余量），单次 read timeout 25s
  - 旧 parser→routing→explainer 管道**保留不删**，仅在 LLM API 故障（抛 `PlannerError`）时由 routes.py 落回——"停电保险"而非并行通道
- 原因:
  - 单管道只能处理"解析成 TaskIntent"的固定形态，"顺路买咖啡""逛遍全校""我这到那"需要多步工具编排
  - 工具错误可回注让模型自修正，比一次性 JSON 解析 + 规则后处理更鲁棒
  - 研究命题（NL→空间参数）不变，weights 改由 LLM 在工具调用中给出，链路更可观测
- 护栏: 路线产出即终止循环（防 DSML 泄漏到前端）；`_sanitize_message()` 兜底剥离；ask_user 为终结型工具
- 影响: 新增 agents/planner.py、tools.py、prompts/agent_system.txt；routes.py /chat 改为 Agent 优先

## DEC-022: 工具集边界 — LLM 只决策，工具只计算

- 日期: 2026-08（补录）
- Decision: 9 个工具：resolve_poi、search_poi_candidates、plan_route、plan_via_route、plan_tour、get_weather、list_road_conditions、ask_user、suggest_followup
- 关键约定:
  - 坐标转换、POI 归一、路网吸附、Dijkstra、顺路比、游览排序全部在工具/空间层，LLM 碰不到图
  - 工具回注结果压缩坐标为"[N 个坐标点]"，完整坐标走 artifact 直传 API（省 token、防模型复述坐标）
  - 天气/路况必须调工具，prompt 铁律禁止凭印象回答
  - 工具失败统一 `{"error","message"}` 回注，不抛异常中断循环
- 影响: agents/tools.py 成为 LLM 与空间层的唯一通道

## DEC-023: 静态记忆 — 任务卡关键词召回注入

- 日期: 2026-08（补录）
- Decision: data/task_cards.json 存校园场景经验（9 张），knowledge.py 每轮按触发词命中数召回 ≤2 张（当季 +1），作为 system 消息注入，卡片可带参考权重
- 放弃方案: 向量检索/RAG——卡片 <50 张，关键词子串匹配足够且零依赖；把经验写死进 prompt——无法独立维护
- 边界: 静态先验优先级低于用户显式要求

## DEC-024: 动态记忆 — 服务端 EMA 用户画像，仅从采纳中学习

- 日期: 2026-08（补录）
- Decision: 按 whu_uid 在 data/user_profiles.json 持久化权重，EMA α=0.3；只在 route_accept 更新，route_shown 仅计数，≥3 次采纳才注入
- 原因:
  - v0.1 的 localStorage 偏好（DEC-008）跨端不同步、易清空；画像需要跨会话服务端化
  - 拒绝/重规划不学习，防止模型被自己的选择循环强化；样本不足宁缺毋滥
- 取舍: JSON+线程锁，多 worker 可能丢更新——画像只是软先验，可容忍；规模化再换 SQLite/Redis
- 配套: POST /api/telemetry（route_shown/route_accept），失败静默绝不影响主流程

## DEC-025: 默认权重按方式区分，步行回归距离主导

- 日期: 2026-08（补录）
- Decision: `MODE_DEFAULT_WEIGHTS`：walk {0.8,0.05,0.15}、bike {0.6,0.25,0.15}、drive {0.85,0.05,0.10}
- 原因: OD 实测旧默认（0.5/0.2/0.3）步行无谓绕路显著；武大主要活动区坡路影响小，slope 默认压到 0.05（绕行 <3%）；骑行坡度权重抬高
- 注记: DEC-004（0.5/0.2/0.3）废止；config.py 中旧 DEFAULT_WEIGHTS 成为无引用僵尸常量，新值以 routing.py 为唯一事实源

## DEC-026: 前端地图迁移 Leaflet + 高德 GCJ-02 瓦片

- 日期: 2026-08（补录）
- Decision: 地图引擎改为本地化 Leaflet 1.9.4，底图用高德瓦片（矢量 webrd style=8、卫星 webst style=6+8，maxZoom 18）；高德 JS SDK 2.0 仅保留做辅助定位，加载失败降级浏览器原生定位
- 原因: 摆脱 JS SDK 渲染黑盒、路径/交互可控可离线本地化；GCJ-02 瓦片与全站坐标统一，无需底图偏移补偿
- 硬约束: 禁止接 OSM/Esri 等 WGS-84 瓦片源（偏移约 500m）；后端 WGS-84 出参一律转换

## DEC-027: 三校区 + 三出行方式扩张，路网与 POI 全量重建

- 日期: 2026-08（补录）
- Decision: 范围从文理单校区扩到文理/工学/信息三学部，420 POI、12 校门；路网 12,550 边；步行/骑行/驾车三方式
- 硬约束: 台阶/电梯/扶梯对 bike/drive 一票否决（filter_graph_for_mode）；步行用 walk 全量路网（沿用 DEC-012）；切换方式用上次路线坐标直接重算，不把"我的位置"当 POI 名查
- POI 纪律: 排除校外地点/居民区/小商铺（is_minor 标记），别名做中文数字归一、宽泛片区词不做子串扩散

## DEC-028: edge_overrides 人工路网覆盖

- 日期: 2026-09（补录）
- Decision: data/edge_overrides.json（208 边）解决 OSM 几何问题：建筑轮廓相交自动检测 + 人工校对；blocked_modes 硬封禁、walk_penalty 软惩罚
- 典型: 穿越建筑边禁 bike/drive（crosses_building）；台阶步行 2.5×；食堂区域 10 条有向边 10× 防穿楼；命名道路不自动封禁
- 原因: 纯 DEM/标注无法识别"路穿楼"这类拓扑语义错误，需人工覆盖层与标注层分离

## DEC-029: 路况全方式生效、边链绑定、定时窗、双通道鉴权

- 日期: 2026-09（补录）
- Decision:
  - CONDITION_EFFECTS 五种类型（closure/construction/flooding/accident/event）对三方式分别定义 block/倍数；**步行不再豁免**（旧"步行不受影响"废止）
  - 事件绑定边而非圆形半径：服务端吸附（30m）后沿拓扑扩展成"路口到路口"边链（≤40 边）；节点 id 失效有 12m 几何回退
  - start_time/end_time 定时生效；PATCH action=end 立即结束但留痕
  - 管理鉴权双通道：网页 session（ROAD_CONDITION_ADMIN_PASSWORD）+ X-Admin-Token/ Bearer（ROAD_CONDITION_ADMIN_TOKEN，hmac 比较）；普通用户只读且只见到生效中事件
  - 路况/管理接口 network-only 缓存，保证强一致
- 降级: 硬封禁导致不可达时转超大惩罚保路线可出

## DEC-030: 语音交互与实时导航（App 原生桥）

- 日期: 2026-09
- Decision:
  - 语音输入用**按住说话**（press/release/上滑取消，30s 自动释放，2.5s 静默超时），弃用华为系统听写全屏面板；原生端枚举 RecognitionService + 系统默认识别器兜底，Manifest 声明 queries 包可见性；聆听态用应用内紧凑胶囊
  - 语音播报 TTS 走队列，App 内经原生 JavascriptInterface 桥
  - 实时导航：路口级 turn-by-turn；距路线 30m 内且运动时箭头吸附**路段方位角**（忽略罗盘磁偏），反向/绕路（>100°）不吸附；跨正北角度展平防 CSS 打转；偏离静默重算
  - GPS/网络定位分储，优先 6s 内 GPS 点，防步行时 WiFi 定位漂移
- 影响: static/js/voice-input.js、voice-output.js、navigation.js；android-app/MainActivity.java

## DEC-033: PWA Service Worker 纪律（含一次回归教训）

- 日期: 2026-09
- Decision: sw.js 三策略（静态 cache-first、/api SWR、第三方与 APK network-only）；改动 PRECACHE_URLS 中任何文件必须同步升 CACHE_NAME 版本号（2026-09 当前 v47）；静态资源 URL 不带 /static/ 前缀
