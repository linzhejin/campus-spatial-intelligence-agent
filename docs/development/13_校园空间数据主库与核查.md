# 校园空间数据主库与核查

## 当前事实

- `data/pois.json` 是线上 POI 正式库，坐标为 GCJ-02；原有 420 条历史记录的逐项来源与现场核实状态尚未补齐，因此统一标为 `legacy_unverified`。新增“卓尔体育馆”对应 OSM `way/869323037`，标为 `source_only`，表示只核对了开放来源，尚未现场确认导航落点。
- `data/whu_road_network.graphml` 是 OSM 路网缓存，坐标为 WGS-84；图中 `osmid` 被整理成路段 `source_refs`，默认 `verification_status=source_only`。边标注文件有 12,550 条，其中 9,510 条带“占位”说明。数值字段覆盖率不能作为实测质量指标。
- `data/edge_overrides.json` 中的建筑相交处理来自几何筛查；加载时标为 `suspected_building_crossing`。它不是现场确认的封路结论。连廊、隧道与建筑内部通道须逐条复核。
- 前端高德底图用 GCJ-02；路网与算法内部保持 WGS-84，只在向前端返回折线和转向点时转换一次。坐标转换不能修复道路缺失或错误几何。

## 数据进入正式库的规则

1. 用 `python scripts/fetch/fetch_pois_osm.py` 生成 OSM 候选、正式库未匹配名称及逐条排除原因。Overpass 不可用时，可从 [Geofabrik 湖北 OSM 快照](https://download.geofabrik.de/asia/china/hubei.html)下载 PBF，安装 `osmium` 后执行 `python scripts/fetch/fetch_pois_osm.py --pbf <快照路径>`。候选不自动入库；名称未匹配不一定代表漏点，可能是别名、相邻设施或错误归属。学校授权矢量数据、Overture Places 和 Foursquare OS Places 如要补充，须另行核对许可、局部覆盖率并整理成同一候选字段；当前尚未接入这些来源。商业地图 API 的返回不进入可再发布的开放主库。
2. 每个候选地点核对名称、别名、类别、学部、坐标和到可导航道路的距离。确定后写入 `data/pois.json`，记录 `source_refs` 与 `verification_status`；纳入或排除决定持久写入 `data/campus_review_decisions.json`。目的地可落在附近通行道路，无需逐栋测量入口。
3. 路段以 `(u,v,key)` 为唯一标识。对现场或校方核实的路段，在 `data/campus_review_decisions.json` 写入 `edge_id`、`verification_status`（`field_verified` 或 `institution_verified`）、`verified_at`、`evidence` 以及 `blocked_modes` / `passable_modes`。加载路网时只应用字段齐全且精确匹配的通行决定。既有 `data/edge_overrides.json` 为几何筛查产生的临时策略，不能当成现场核实。
4. `python scripts/validate/audit_campus_master.py` 输出当前来源指纹、缺失候选、占位标注、POI 吸附距离和道路风险队列到 `scripts/audit_output/campus_spatial_quality.json`。风险优先级先处理疑似穿楼，再检查台阶附近车行道、多重边、校门连接及断头路。审计报告可反复生成，核实结论只写入持久决策文件；原始审计文件缺失时报告会明确标注。
5. `data/route_reference_samples.json` 定义同一批跨学部、山路、边界和体育馆起终点。配置高德 Web 服务 Key 后，可用 `python scripts/validate/compare_walk_reference.py` 生成距离差与折线偏差指标。脚本只保存派生指标及自有 OSM 边 ID，不缓存高德路线折线。差异是现场核查线索，不能直接以某一家商业路线作为真值。
6. 完成前三项审计后运行 `python scripts/validate/check_deployment_readiness.py`。发布门槛要求开放来源候选逐条裁决、正式地点与高风险路段有核实证据、占位属性已处理、导航落点和代表性路线已核查。门槛未通过时不应将自动校验的成功等同于数据验收通过。

## 发布和论文验收

- 地点：三学部教学楼、食堂、宿舍、图书馆、体育设施与校门的正式名称及常用别名可检索；缺项清单逐条有纳入或排除结论。
- 道路：代表性 OD 每段有实际可通行性记录；确认不可通行的边在对应出行模式下被移除；桥、连廊、隧道的例外保留证据。
- 画线：推荐路和最短路分别保存具体 `(u,v,key)` 序列，距离、成本、转向与返回前端的折线均按该序列计算。任何底图偏差记录涉及的边 ID、来源几何、现场或影像证据和处置结果。
- 来源：开放数据版本与处理代码保留；OSM 衍生成果遵守 ODbL，校方数据遵守授权范围，商业 API 内容只按服务协议线上使用。

当前还没有覆盖三学部全部地点与道路的校方授权数据，也没有完成全路段现场核查，因此不能将上述自动审计结果表述为“数据完整”或“路线已验证可靠”。

2026-09-25 使用 Geofabrik `hubei-260924.osm.pbf` 快照对照：提取 314 个校内候选要素，232 个与正式库名称或别名匹配，82 个名称未匹配，待逐项判定；卓尔体育馆 OSM `way/869323037` 与正式库位置相差约 0.1 米。6 组自有路线与高德步行路线对照均成功，但折线的对称 95 分位偏差为 59.2–98.9 米，且部分推荐路线穿过建筑相交风险边。高德仅是参照，这些差异尚无现场裁决，当前不满足发布验收条件。

同日 120 组随机 OD、步行/骑行/驾车两版各 360 次规划的对照：现行覆盖策略把步行疑似穿楼边出现次数从 22 降到 8、骑行从 34 降到 1；骑行不可达从 39 组升到 46 组。两侧存在可通行性风险，不能把几何筛查生成的封禁视为已核实道路结论。完整控制台记录在本地 `scripts/audit_output/route_quality_matrix_120.txt`（审计输出目录不入库）。

代码全量测试结果：423 通过、5 跳过、1 项预期失败；结构校验 421 个正式 POI 无必填项、坐标范围、学部归属和重名错误，12,550 条图边均有标注记录。发布门槛另行失败：82 个开放候选未裁决、421 个正式 POI 缺完整核实状态、9,510 条占位标注、1,202 条风险边未核实、8 个 POI 吸附超过 50 米、6 条代表性路线未现场核实。标注记录覆盖率不等于属性真实度。

## 2026-09-26 数据链路复核

- 本地湖北 OSM PBF 已按三学部完整关系面提取：2,994 条道路候选、559 个出入口与障碍节点、1,138 个建筑轮廓；2,805 条非面积道路组成隔离的候选图（11,052 节点、24,860 有向边）。候选图保存在 `scripts/audit_output/whu_road_network_candidate.graphml`，未覆盖正式路网缓存。重新从本地证据生成的 603 个校内具名 POI 候选中，仍有 298 个尚未与正式库匹配并裁决。
- 历史高德抓取脚本把信息学部查询锚点放在外校附近，范围多边形又覆盖华中师范大学和武汉体育学院。已将三个查询锚点移入各自学部，候选入库范围改为 OSM 三学部面；高德在线导航入口查询也改用武汉全市范围。12 个明确落在华师或武体面内的历史地点已归档至 `data/pois_excluded_legacy.json`，原记录可恢复。新增 4 个独立体育设施的 OSM 具名候选后，正式库为 439 条；来源状态仍须现场核实。
- 高德 Web 服务 `place/text` 在武汉全市查询“玉兰2门”和“玉兰二门”均返回 0；截图估计位置附近 250 米 `place/around` 搜“玉兰”或“门”，以及约 800×550 米 `place/polygon` 搜同样关键词，也均返回 0。正对照查询在同区域搜“武汉大学”分别得到 88 和 100 条，说明接口和密钥可用，但这些查询不能取得该底图标注。用户提供的高德底图截图有“玉兰2门”标注，不能把 API 未命中解释为地点不存在。OSM 附近无名门节点 `node/1204194363` 有 `foot=yes`，但尚无名称绑定证据；另一个附近门 `node/9555357538` 为 `foot=permit`。位置推断和待核实条件记录在 `data/gate_name_review_candidates.json`，目前未发布为“玉兰2门”。
- 候选路网按来源标签排除 `entrance=emergency`、`foot=permit`、`access=private` 等受限连接；`indoor=yes` 且无明确步行许可的通道不作为普通室外步行路线。API 对已知地点优先使用高德本次请求返回的 `entr_location` 导航入口。路线对照脚本现采用同样的终点策略，不保存商业 API 折线或入口坐标。
- 六组参考 OD 在正式图和候选图上都能完成高德步行对照。候选图中“文理—工学”路线 95 分位折线差约 45 米，“信息—文理”约 38 米，且这两条不再经过审计发现的室内穿楼边或应急入口。候选图在“樱花大道—珞珈山”一组仍与高德相差约 458 米；正式图该组约 81 米。候选图另一组有一条 6 米左右、标为 `covered=yes` 的建筑相交步道，需现场确认是否为合法有顶通道。地图商几何不是通行真值，不能只因数值更接近就替换正式图。
- 隔离候选图对两处离校园边界较远的正式附属地点（珞涵屯、口腔医院）贴路超过 50 米。审计及发布门槛现会阻止这种覆盖倒退，也会查出再次混入其他学校边界的正式地点。两处附属地点须决定导航范围和连接方式后再替换路网。
