# 课程空间数据融合与验收

## 融合原则

- 保留 **OSM 路网 + 高德在线服务** 的混合架构。OSM 是开放底稿；课程数据在可唯一对应的道路上补充、纠正静态属性和几何；高德仅在线提供底图、POI/路线参照，不将商业 API 返回数据并入可再发布的路网。
- 课程数据来自本机课程目录 `C:\Users\HUAWEI\Desktop\homework\空间分析练习\2026空间分析\RoadNet`，包含 `whu_road.shp`、`whu_spot.shp` 及其 sidecar。道路和地点原始 CRS 为 EPSG:4547。源文件不复制进应用仓库。
- 坐标仅按数据流转需要转换：道路线存 WGS-84；前端高德底图与正式 POI 坐标用 GCJ-02。课程地点从 WGS-84 转 GCJ-02 一次。坐标转换不等于现场核实，也不能补出缺失的路。
- `data/whu_road_network_osm_base.graphml` 是可重复构建的只读 OSM 输入，`data/whu_road_network.graphml` 是应用实际读取的融合运行图；重建永远从前者开始，避免重复叠加课程数据。
- 课程道路线的 Z 值全为 0，不是实测高程；本轮不生成坡度、海拔或风景评分。原有路线属性只在来源、对应关系和空间几何检查通过后保留；数据未知就保持未知。
- 课程数据没有提供明确再发布许可，发布包记录 `not_established`。OSM 衍生内容仍按 ODbL 管理；地图商路线折线不落入正式主库。

## 当前已入库内容

正式 POI 数量仍为 439，没有新造重复 ID。`data/pois.json` 中 5 个已有地点由课程点位校正坐标，并增加课程来源与坐标历史：遥感学院对应 `poi_247`、校门牌坊对应 `poi_140`、校史馆对应 `poi_034`、行政楼对应 `poi_035`、万林博物馆对应 `poi_004`。遥感学院新增常用别名“遥感学院”“信息学部遥感学院”；校门点增加“武汉大学校门牌坊”等别名。它们的课程来源状态是 `source_only`，不能称作现场核实。

道路源有 647 条。当前匹配统计为 197 条唯一匹配、440 条歧义、10 条新候选。最终发布校验中：

- 88 条课程道路的几何替换了 322 条有向 OSM 边；每条替换边仍保留 OSM 与课程两种来源。
- 159 条唯一匹配课程道路应用了静态属性，其中 71 条只应用属性、保留 OSM 几何；一共影响 710 条有向边。静态冲突不会按输入先后任意覆盖。
- 38 条唯一匹配没有通过逐边安全门槛，保持原样并列为未应用；440 条歧义匹配不自动入库。10 条新候选中 5 条仍待定；5 条形成步行专用连通组件。新路不进入骑行或驾车图。
- 属性覆盖数不代表实地通行核实。课程没有坡度数据，新增内容不调整最短路权重或通行权限。

## 自强大道拓扑例外

用户确认珞珈广场旁课程道路第 393、394 行的断开是课程拓扑练习的一部分，不能当作封路。实测课程折线端点间距约 140.29 米；两端分别吸附到原 OSM 节点，距离约 4.05 米和 2.30 米。原 OSM 步行路网与融合发布图都保留约 161.51 米的步行连通路线。

此决定写在 `data/course_topology_exceptions.json`，证据状态为用户提供、尚非现场核实。构建时会拦截步行封禁、失去原步行连通、端点无法安全吸附或将断开的课程线误激活为孤立新连接器。它不会生成跨越约 140 米缺口的直线，也不会把自强大道标为关闭。

## 构建、审计与剩余事项

本机重新构建命令：

```powershell
python scripts/network/build_course_data_release.py `
  --source-dir 'C:\Users\HUAWEI\Desktop\homework\空间分析练习\2026空间分析\RoadNet' `
  --base-graph data\whu_road_network_osm_base.graphml `
  --pois data\pois.json `
  --crosswalk data\course_poi_crosswalk.json `
  --topology-exceptions data\course_topology_exceptions.json `
  --output-dir output\course_fusion\release
```

`output/course_fusion/release/release_manifest.json` 记录来源文件指纹、输入输出哈希、匹配裁决、路径连通检查和 GraphML 往返校验。原 POI 库的可回滚副本位于发布包 `rollback/` 目录；中间审计包不作为应用正式库。

课程数据不能补齐的 POI 或路线仍由既有 OSM/高德链路处理。本次课程文件不含“玉兰2门”；当前正式 POI 和 OSM 候选快照也没有该名称，高德地点文本 API 对“玉兰2门”“玉兰二门”均未返回精确匹配。底图瓦片能显示文字，不等于地点检索 API 一定有同名 POI。现阶段不得猜测门点坐标或用相似名称替代。“澄波门”已在正式库中，记录为 `poi_419`，来源是 OSM `node/1197839325`，状态仍为 `source_only`。

“卓尔体育馆”已存在于正式库，记录为 `poi_418`，不是课程点位新增项。当前图上从 POI 中心到最近路网节点约 57.6 米；线上比较时，高德入口与 POI 中心相距约 97.9 米，但路线实际从同一个高德入口起步。入口在线解析可改善落点，离线 POI 中心仍需现场或校方核实，不能把其中任一坐标直接宣称为实测入口。
