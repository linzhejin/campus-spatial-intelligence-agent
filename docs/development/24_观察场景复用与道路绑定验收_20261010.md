# 无人机观察场景复用与道路绑定验收（2026-10-10）

## 本次交付

- 管理员可给常用机位命名并保存参考位置、相机稳定状态、观察区域和路段绑定。场景保存在 PostgreSQL；删除场景不会删除已提交的影像任务。
- 复用场景前，浏览器先比较画面指纹；提交影像时，服务器独立计算并再次比较。差异超过 8/64 位时拒绝复用，不把可能失配的区域交给分析队列。
- 复用时，机动车道、人行区、路面区必须绑定道路。保存和提交都会按当前路网重新吸附，并核对原有边 ID；路网变化或道路已失配时要求管理员重新选路。
- 管理员可在地图上为某个观察区域绑定、清除或重新选择路段。选择用于道路关联的点和保存的 ROI 分开显示；“绑定到某条路”不声称影像里的检测框已精确投影到地面。
- 图片直传和视频分块续传都传递场景信息；视频仍按首帧做视角筛查。已保存的区域、道路和影像场景 ID 会随任务保存，供后续审计。

## 安全与适用范围

画面指纹是轻量 dHash，只能筛除明显不同的画面，不是摄影测量、相机标定或正射校正。视频首帧相符不证明后续画面视角不变。管理界面要求复核区域和道路；镜头移动时应重新圈选/关联。观察场景只能让重复管理操作少做几步，不能代替影像空间配准。

检测框仍在影像像素坐标中。车辆、行人、拥堵与人流线索须按现有逐项审核流程处理；事故和积水专用模型仍未达到启用标准，保持关闭。没有武大航拍样本，因此本次结果只证明软件数据链路，不代表校园识别精度或现场路线安全已验收。
