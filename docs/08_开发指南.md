## 数据校验

```bash
python scripts/validate/validate_all_data.py
```

7 项校验：
1. 字段完整性
2. 坐标合理性
3. 类型合法
4. campus 归属正确
5. 不在多边形外的 POI
6. 无重名
7. 无别名冲突

## 新增 POI 流程

1. 在 `data/pois.json` 添加条目（id 唯一，含 name/aliases/coordinates/type/campus）
2. 运行 `python scripts/validate/validate_all_data.py` 校验
3. 运行 `pytest tests/test_poi.py` 确保不破坏现有匹配
4. 若 POI 有别名，确保不与现有 POI 的 aliases 冲突

## 路网重建

```bash
python scripts/network/rebuild_network.py    # 下载并裁剪
python scripts/network/compute_slope_from_dem.py  # 计算 DEM 坡度
python scripts/network/clip_to_campus.py      # 按校园多边形裁剪
```

裁剪后自动备份原文件为 `*.bak-campus`（现已清理，仅保留裁剪后版本）。
