# 08 · 开发指南

## 环境配置

Python 3.11+（生产基准 3.11；代码用到 `str | None` 注解，最低 3.10）。

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -r requirements-dev.txt  # osmnx/geopandas（重建路网）+ pytest
```

`.env` 至少配置 `DEEPSEEK_API_KEY`、`AMAP_KEY`、`AMAP_SECURITY_CODE`（完整清单见 [02_快速开始](02_快速开始.md)）。本地启动：`python app.py`，访问 http://localhost:5000 。

## 架构速览

- **主通道（v2 全 Agent）**：`POST /api/chat` → [agents/planner.py](../agents/planner.py) 的 `run_agent()` 执行 Plan-Act-Observe 循环（`MAX_TURNS=6`、`TIME_BUDGET_S=40`、temperature=0），由 LLM 决策调用 [agents/tools.py](../agents/tools.py) 中 9 个 function-calling 工具：
  `resolve_poi`、`search_poi_candidates`、`plan_route`、`plan_via_route`、`plan_tour`、`get_weather`、`list_road_conditions`、`ask_user`、`suggest_followup`。
- **兜底通道（停电保险，不是备用路径）**：LLM 断网/鉴权失败导致 `PlannerError` 时，[api/routes.py](../api/routes.py) 的 `chat()` 捕获后落回旧管道 [agents/parser.py](../agents/parser.py)（`parse_query()` + 规则后处理 + explainer）。
- 空间计算：[spatial/routing.py](../spatial/routing.py)（方式过滤、多因素 Dijkstra、转向指令、途经点/游览）、[spatial/road_conditions.py](../spatial/road_conditions.py)（边绑定路况）、[spatial/poi.py](../spatial/poi.py)、[spatial/network.py](../spatial/network.py)、[spatial/coord_transform.py](../spatial/coord_transform.py)（GCJ-02 ⇄ WGS-84）。
- 知识与画像：[agents/knowledge.py](../agents/knowledge.py)（任务卡注入）、[agents/profile.py](../agents/profile.py)（EMA 权重先验）。

## 新增 POI 流程

1. 在 `data/pois.json` 添加条目：`id` 唯一（`poi_NNN`），含 `name`、`aliases`、`coordinates`（**GCJ-02**）、`type`、`subcategory`、`campus`；
2. 宽泛片区名（如「X园」「X学部」）不要挂到单栋建筑别名上，需要代表点时走 `scripts/data/add_area_centroids.py` 的区域质心方案；
3. 运行 `python scripts/validate/validate_all_data.py` 与 `python -m pytest tests/test_poi.py tests/test_two_stage_poi.py`；
4. 别名冲突由校验脚本兜底（别名不能等于其他 POI 的正式名）；
5. 坐标来源优先高德（GCJ-02 可直接入库）；OSM/WGS-84 坐标必须先转换。

## 路况规则

事件绑定具体路段（`snap_to_edge` 吸附 30m 内最近边并沿拓扑扩展成「路口到路口」边链，上限 40 边 / 600m）。影响矩阵以 [spatial/road_conditions.py](../spatial/road_conditions.py) 的 `CONDITION_EFFECTS` 为准，**对所有出行方式生效**：

| 类型 | 步行 | 骑行 | 驾车 |
|---|---|---|---|
| 封闭 closure | 硬封 | 硬封 | 硬封 |
| 施工 construction | 1.5× 软惩罚 | 硬封 | 硬封 |
| 积水 flooding | 硬封 | 硬封 | 1.5× 软惩罚 |
| 事故 accident | 1.3× 软惩罚 | 1.3× 软惩罚 | 硬封 |
| 活动 event | 1.2× 软惩罚 | 1.2× 软惩罚 | 硬封 |

硬封 = 从方式图移除边；若因此不可达，规划器软降级重试（封闭边 1000× 成本）并在 `filter_status` 标 `degraded_road_closure`，仍不可达才给友好提示。前端 [static/js/app.js](../static/js/app.js) 的 `CONDITION_MODE_EFFECTS` 与后端同表，改表时两处同步。端点共 5 个，详见 [04_API参考](04_API参考.md) 与 [03_部署指南](03_部署指南.md) 的鉴权说明。

## 添加新出行方式

以新增 `moto`（示例）为例，按以下顺序改全：

1. **[spatial/routing.py](../spatial/routing.py)**
   - `TRAVEL_MODES` 加 `"moto"`（`normalize_mode` 白名单即由此派生，非法值仍回退 walk）；
   - 补 `MODE_SPEEDS_KMH`、`MODE_DEFAULT_WEIGHTS`（distance/slope/scenery，和为 1）、`MODE_OUTSIDE_ROAD_PENALTY`；
   - 在 `filter_graph_for_mode()` 加分支：按 `highway` 标签决定剔除哪些边（参考 `_NON_VEHICULAR_HIGHWAY` 一票否决与 `_DRIVE_ALLOWED_HIGHWAY` 白名单写法），必要时加模式专属 penalty_map（参考 bike 对 slope_level 4/5 的 1.5×/3×）。
2. **[agents/parser.py](../agents/parser.py)**：加 `_MOTO_MODE_PATTERN` 关键词正则，并在 `detect_travel_mode()` 中按顺序接入（现有顺序 bike → drive → walk，关键词集合不可互相重叠，「车」单字不参与匹配）。
3. **[agents/tools.py](../agents/tools.py)**：`_PREFERENCE_SCHEMA` 的 `mode` enum（`plan_route` / `plan_via_route` / `plan_tour` 共用）加 `"moto"`；`_plan_common()` 的合法值集合同步。
4. **[agents/planner.py](../agents/planner.py)**：`_MODE_VERB`（L65）加中文动词（如 `"moto": "骑电动车"`）用于结果话术；`run_agent()` 注入前端方式的白名单元组（L121，现为 `("walk","bike","drive")`）也要加新值，否则前端切换的 `travel_mode` 不会注入上下文。
5. **前端**：
   - [static/index.html](../static/index.html) 加 `<button class="travel-mode-btn" data-travel-mode="moto">`；
   - [static/js/app.js](../static/js/app.js) 的 `TRAVEL_MODES` 加 `label/color/speedKmh/loadingText/loadingSub`（请求体字段 `travel_mode` 自动带上）；
   - [static/css/style.css](../static/css/style.css) 补按钮/路线配色。
6. **测试**：在 `test_routing.py`（方式过滤/权重）、`test_parser.py`（关键词检测）、`test_road_conditions.py`（影响矩阵如需新模式差异化）补用例，`python -m pytest tests/` 全过（当前基线 373）。

## 代码风格

- Python 3.11 基线，类型注解（`dict | None` 新式 union），Pydantic v2 校验入参；
- Flask Blueprint（`api/routes.py`，统一 `/api` 前缀）组织接口，`logging` 统一日志；
- LLM 温度：planner/parser `temperature=0.0`（确定性决策）；explainer 各生成函数 0.3–0.6（解释/闲聊允许发散）；
- 坐标纪律：入库与前端一律 GCJ-02，OSM 路网 WGS-84，边界处用 `spatial/coord_transform.py` 显式转换；
- 工具内部异常必须转成 `{"error": ..., "message": ...}` dict 回注 Agent，不允许抛出中断循环。
